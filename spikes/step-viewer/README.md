# Burr STEP Viewer Spike

This spike answers one question: can Burr render a real STEP artifact entirely
inside the browser before any `burr .` server or repository restructuring is
built?

```bash
npm install
npm run dev
```

The page loads `public/counterbore.step`, generated by Burr's existing
`examples/build123d-counterbore/good/design.py` fixture. It also accepts a local
`.step` or `.stp` file through the file picker. Parsing runs in a Web Worker;
the page has no upload endpoint.

Out of scope: folder scanning, file watching, receipts, editing, generation,
and runtime packaging inside the Rust executable.

## Third-party runtime

- [`occt-import-js`](https://github.com/kovacsv/occt-import-js), LGPL-2.1,
  provides the separately loaded OpenCascade WebAssembly parser.
- [`three.js`](https://github.com/mrdoob/three.js), MIT, provides WebGL rendering
  and camera controls.
